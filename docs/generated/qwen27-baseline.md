# Qwen3.8 27B: specrt against vLLM

The vLLM baseline for the 27B NVFP4 and specrt on the same harness. The last section is written by `crates/specrt/scripts/baseline_report.py docs/generated/qwen27-run --update-doc docs/generated/qwen27-baseline.md` (run by `specrt_baseline.sh`); `crates/specrt/tests/baseline_report.rs` checks it against the JSON in `qwen27-run/`.

## The vLLM run

| | |
|---|---|
| Model | `orcarouter/Qwen3.8-27B-Uncensored-NVFP4` (compressed-tensors, mixed precision) |
| Engine | vLLM 0.27.1, one GPU, `FLASHINFER` attention, `FlashInferCutlassNvFp4LinearKernel` |
| GPU | RTX PRO 6000 Blackwell Max-Q, 96 GB, local-llm.service stopped, 10 Nov 2026 (#307) |
| Launch | `crates/specrt/scripts/vllm27b_serve.sh mtp` and `nomtp` on port 8011: `--max-model-len 262144 --max-num-seqs 32 --max-num-batched-tokens 16384 --kv-cache-memory-bytes 14G --kv-cache-dtype fp8 --enable-prefix-caching`, MTP with 2 speculative tokens |
| Harness | `crates/specrt/scripts/vllm_baseline.py`: streaming chat, `ignore_eos`, thinking off, a unique prompt per request so the prefix cache only hits where a suite asks for it. MTP on and off are two sequential launches |
| KV capacity | 400,663 tokens with MTP, 439,919 without |
